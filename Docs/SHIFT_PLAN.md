## Контракт интеграции

- Visual Director создаёт префаб комнаты с отдельными объектами и точками взаимодействия для героя/кровати, часов, полки и двери. UI/UX делает лейблы и действие по наведению. Game Mechanics подключает запуск следующего сна через тот же объект.
- Level Design передаёт семь геометрий с точками старта, кроватями-выходами и размещёнными ловушками. Game Mechanics подключает поведение и бесконечный цикл без изменения геометрии на последующих кругах.
- Sound Design передаёт рабочий способ вызова звуков и несколько вариантов. Game Mechanics использует его из геймплея, UI/UX — из меню.
- Палитра UI ТЗ распространяется на весь проект. Если не хватает графики, использовать генерацию изображений и Tessera; сохранить исходники и обработанные временные ассеты отдельно.
- Все экраны актуального UI работают; Game Over и Victory исключены. Касание ловушки возвращает на текущий уровень, завершение сна возвращает в слегка изменённую комнату.
- Каждый исполнитель назначает отдельного проверяющего сабагента по своему направлению. Проверяющий смотрит результат и тестовые доказательства, формулирует замечания; исполнитель исправляет их. Самоприёмка не считается проверкой.

## Проверка готовности

Приёмочный путь: комната-меню → засыпание → семь коротких уровней с переходами через комнату → новый цикл по тем же геометриям со случайной сменой стилистики. Проверить ловушки, таймерные кнопки, анимацию повтора, плавную камеру, следы краски до выхода с уровня, аудио и все актуальные UI экраны. Должна быть Windows-сборка и проверка запуска; автоматическая компиляция сама по себе не доказывает визуальное качество, звук и удобство управления.

Рабочее допущение для лазера до визуальной приёмки: требование «хитбокс 3–4 пикселя» относится к пикселям внутреннего низкоразрешённого игрового рендера. Ширина луча и триггера выводится из параметров камеры и RenderTexture, а не задаётся константой в Unity units.

После написания кода исполнитель ищет задачу с точным названием «Документация» только в этом проекте или репозитории (совпадает projectId либо абсолютный корень `T:\Sleepwalking`). Если подходящей задачи нет либо принадлежность не подтверждается, ничего не отправляет.
