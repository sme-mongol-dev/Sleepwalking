    Poster, bed и shelf: ровно один вариант при каждом значении 1–100. Bed задаёт резервный кадр; до первого сна герой дышит, после него водит взглядом. Трещина 4: три стадии роста 30%, 60%, 100%, затем четвёртая стадия — глаз со зрачком на том же месте. У трещины 5 три стадии роста. Задайте Min для каждой стадии, Max вычислится автоматически. Calendar и трещины могут отсутствовать до первого порога. В экспорт входят только строки с изменениями; остальные значения остаются из префаба.
