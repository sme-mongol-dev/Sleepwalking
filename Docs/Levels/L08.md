# L08: switches and shuttle

Implemented on `ui-fix` after integrating `main` at `f800138`. The scene keeps the two tutorials, then runs L01–L08. Completing L08 starts another cycle at L01. Odradek uses the current level count and a 40-second reference time for L08.

## Layout

The supplied transparent drawing is [L08-layout.png](L08-layout.png). Its black platform outlines are visible in the [white-background preview](L08-layout-white.png). [Runtime overview at Odradek 100](L08-runtime.png).

Positions below are in grid cells; one cell is 32 Unity world units.

| Part | Position / behavior |
| --- | --- |
| Start | X 1.7, floor Y 0 |
| First ledge | X 3–8, top Y 3; climb its left side |
| `+` switch | X 4.5; disables both saws for 32 seconds before the Odradek multiplier |
| Laser | X 6.3, between Y 3 and 4.5; jump over the beam on the first pass |
| Shuttle | Center X 9–15, top Y 3; horizontal movement, eight-second full cycle |
| Lower recovery pads | X 14–16 at Y 1, X 18–20 at Y 0 |
| Raised ledge | X 16–20, top Y 5 |
| `−` switch | X 18; disables the laser beam for 18 seconds before the Odradek multiplier |
| Exit saw | X 21.2, Y 7.3; shares the `+` switch with the upper-left saw |
| Exit | Jump and dash onto X 22–26 at Y 7; bed at X 24.2 |

The drawing's yellow and burgundy circles are interpreted as saws. Movement, the first laser's clearance, and platform heights are tuned to the existing controller. The imported `main` contract remains in effect: a laser switch disables its beam while its emitter stays lethal. Visible spikes below the route cause a normal death and retry. Every authored tile surface has a solid contour collider.
