# Локации-сны

Предварительный перечень локаций для левел-дизайна, в порядке, названном пользователем:

1. **Мясная локация** — [визуальный референс](UI/References/TL_Meat_Dream.png).
2. **Военный постапокалипсис** — [визуальный референс](UI/References/TL_PostApoc_Dream.png).
3. **Глубокие воды** — [визуальный референс](UI/References/TL_DeepWater_Dream.png).
4. **Райские облака** — [визуальный референс](UI/References/TL_Heaven_Dream.png).

Названия условные. В MVP планируются семь коротких геометрий уровней. Для первого цикла стили задаются вручную после готовности геометрий. Далее цикл повторяется бесконечно: геометрии остаются теми же, а стилистика каждой геометрии выбирается случайно в новом цикле. Точное распределение первого цикла пока не задано.
