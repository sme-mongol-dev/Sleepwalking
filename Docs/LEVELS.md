# Локации-сны

Предварительный перечень локаций для левел-дизайна, в порядке, названном пользователем:

1. **Мясная локация** — [визуальный референс](UI/References/TL_Meat_Dream.png).
2. **Военный постапокалипсис** — [визуальный референс](UI/References/TL_PostApoc_Dream.png).
3. **Глубокие воды** — [визуальный референс](UI/References/TL_DeepWater_Dream.png).
4. **Райские облака** — [визуальный референс](UI/References/TL_Heaven_Dream.png).

Названия условные. Сейчас есть два обучающих уровня и семь основных геометрий. При первом прохождении стили идут по кругу: небо → глубокие воды → военный постапокалипсис → мясо. Tutorial 1 получает небо, Tutorial 2 — воду, L01 — войну, L02 — мясо; порядок продолжается до L07. Далее основные геометрии повторяются бесконечно с независимо выбранным случайным стилем, а их форма остаётся неизменной.
