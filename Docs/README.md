# Sleepwalking — документация игры

## Основа

- Жанр и визуальный стиль: пиксельный платформер.
- Проект создаётся в Unity как трёхмерная игра.
- Камера — ортографическая.
- Облик персонажа пока не утверждён: это может быть желейное существо или человек.
- Референс для механики платформинга — Super Meat Boy.

## Игровой цикл

- Комната служит главным меню; из неё герой попадает в кошмар через кат-сцену засыпания.
- После завершения каждого сна герой просыпается в слегка изменившейся комнате. Через героя или его кровать запускается следующий сон.
- Выход с уровня выглядит как кровать: персонаж ложится в неё спать.
- Семь коротких геометрий повторяются бесконечно; после первого цикла для каждой геометрии случайно выбирается стилистика, а её форма остаётся неизменной.

## Платформы

- По длине: длинная и короткая.
- Есть движущиеся платформы: вверх-вниз и вправо-влево.
- Предусмотрены горизонтальные версии платформ.
- При контакте с горизонтальными платформами игрок постепенно скатывается вниз.

## Препятствия

- Шип.
- Пила.
- Лазер: треугольное опасное основание и луч толщиной хитбокса 3–4 пикселя, который тянется до платформы выше либо до края экрана.
- Временная платформа: со временем чередует доступное и недоступное состояния.

## Кнопки

- Кнопки отключают лазер, пилу и шип. Соответствие кнопок препятствиям пока не уточнено.

## Столкновение с опасностями

- Касание шипа, пилы и других враждебных объектов срабатывает с одного контакта: после короткой анимации персонаж возвращается в начало уровня, а камера плавно скользит следом.
- В месте контакта с ловушкой появляется визуальный эффект.
- Следы краски в местах контакта остаются видимыми до выхода с текущего уровня, затем очищаются; после перезапуска игры они не сохраняются.
