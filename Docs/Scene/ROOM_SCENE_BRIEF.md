# Сцена комнаты по видео — отдельная задача MVP

Референс: [видео комнаты](References/gemini_generated_video_9d15d735.mp4), получено 14.11.2026.

Контрольные кадры для работы без видеоплеера: [начало](References/Frames/room-00.png), [пробуждение](References/Frames/room-02.png), [середина](References/Frames/room-05.png), [повторное засыпание](References/Frames/room-07.png). Кадры извлечены из сохранённого MP4 без изменения исходника.

Запрос пользователя: «Из этого видео собери сцену, мне нужны отдельные объекты комнаты, чтобы я мог их менять».

Требования для отдельной задачи:

- Собрать сцену комнаты в текущем Unity-проекте, используя видео как визуальный референс.
- Элементы комнаты создать отдельными редактируемыми объектами Unity, чтобы каждый можно было менять независимо.
- Не объединять всю комнату в одно изображение или один неразделимый объект.
- Использовать комнату как сцену главного меню. В ней должны быть возможны изменения обстановки, которые по ходу игры показывают, что герой всё ещё спит.
- После каждого завершённого сна герой возвращается в комнату; обстановка меняется слегка, без отдельного действия игрока в комнате.
- Собирать комнату как 3D-сцену, сохраняя отдельные редактируемые объекты. Итоговое изображение должно иметь пиксельный вид.
- Сделать предметы комнаты интерактивными пунктами главного меню. При наведении показывать лейбл соответствующего действия.
- Назначения предметов: герой или его кровать — вход в первый и последующие сны; часы — Settings; полка с книгами — Credits; дверь — Quit.
- Если для комнаты не хватает визуального ассета, подготовить временный через генерацию изображений и Tessera, сохранив редактируемую 3D-структуру комнаты.

Сборку комнаты пользователь выделил в отдельную задачу для будущей смены; при этом готовая комната обязательна для MVP. Состав объектов и детали их реализации определить в этой задаче. Связанные переходы описаны в [игровом цикле](../GAME_FLOW.md).
